## Optimization Process

1. Collect Search Console query data.
2. Identify queries generating impressions.
3. Group queries by search intent.
4. Identify pages ranking approximately positions 5-20.
5. Improve relevant titles, content, and internal links only when the page already matches the query intent.
6. Monitor CTR and position changes after each change.
7. Do not optimize solely for keyword frequency.

## Opportunity Rules

### High Priority

- High impressions + low CTR.
- Position 5-20 with strong relevance.
- Queries where the correct page already exists.

### Medium Priority

- Relevant queries ranking 20-50.
- Queries showing growing impressions.
- Related service or location queries that match existing page intent.

### Low Priority

- Irrelevant queries.
- Queries with no meaningful business intent.
- Queries requiring a completely different page intent.

## Guardrails

- Do not create pages simply because a keyword exists.
- Do not keyword-stuff titles, headings, body copy, alt text, or internal anchors.
- Do not add hidden text.
- Do not fabricate Search Console data, rankings, clicks, reviews, awards, offices, branches, employees, or client claims.
- Keep location pages as service-area pages. Only Kozhikode may reference the real office.
- Preserve the current sitemap, robots.txt, canonical URLs, Organization schema, LocalBusiness schema, NAP consistency, verified social `sameAs`, and clean navigation architecture.
